GS-One External API

REST: /api/v1 · GraphQL: /api/graphql · OpenAPI: /openapi.json

User login API

POST /api/v1/auth/login
{"identifier":"username-or-email","password":"..."}

POST /api/v1/auth/register
{"username":"name","email":"optional@example.com","password":"..."}

Login returns a gs_session_... bearer token. Signed-in users can create their own API keys at /api/v1/api-keys.

External API authentication

Authorization: Bearer sk_test_...

GraphQL login

mutation {
  login(identifier:"name", password:"...") {
    token
    user { id username }
  }
}

GraphQL generate

mutation Generate($input: GenerateVideoInput!) {
  generateVideo(input: $input) { success code generation { id status videoUrl error } }
}

Note: both video API styles share the same generation service. The core GenerateVideo behavior is still pending migration and returns an explicit error until connected.
